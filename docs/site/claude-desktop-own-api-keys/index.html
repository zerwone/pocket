Claude Desktop on your own API keys

Claude Desktop has a third-party mode that sends inference to a gateway you choose instead of a Claude account. pocket can be that gateway, on your machine.

How

  1. Run pocket and click Connect next to Claude Desktop. It gives you a file to import.
  2. In Claude Desktop, signed out: Help → Troubleshooting → Enable Developer Mode, then Developer → Configure Third-Party Inference.
  3. Import the file (or set Gateway, the URL and key pocket shows), Apply Changes, restart, and choose the third-party option.

Know before you switch

  • Third-party mode doesn't use your Claude account; its chats stay on your computer. Go back any time with the Anthropic sign-in.
  • Without an Anthropic API key in pocket, answers come from free open models, which are weaker than Claude.
  • This follows Anthropic's gateway docs; it is new in pocket 0.3.0. If the app's connection test fails, open an issue.

FAQ

Can Claude Desktop use my own API key?

Yes, through its third-party inference mode, which needs Developer Mode. Point it at a gateway such as pocket, which sends requests to your Anthropic key or free fallback keys.

Does this affect my Claude subscription?

No. Third-party mode is separate from your Claude account; switch back with the Anthropic sign-in on the sign-in screen.
