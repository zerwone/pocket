Claude Code with free models, as a fallback

Claude Code can talk to any server that speaks the Anthropic API. pocket is that server on your own machine: it translates to Groq, NVIDIA and OpenRouter, keeps your keys in the OS keychain, and fails over between them.

Free keys pocket uses by default

ProviderFree per key
Groq1,000 requests/day
NVIDIA~40 requests/min
OpenRouter50 requests/day (1,000 after a one-time $10 top-up)

Also supported, off until you turn them on because of data or trial terms: Mistral, Google Gemini, Z.ai, Kilo, Cohere, Vercel AI Gateway, Cerebras (trial only). Checked against each provider's docs; the README has the sources and the providers left out.

Why not just set ANTHROPIC_BASE_URL to one provider?

You can. One provider means one limit, and most don't speak the Anthropic API, so tool calls break. pocket translates, retries the next key on a 429, drops models a provider retires, and names the model answering in the session.

Set it up

$ npm i -g @zerwone/pocket
$ pocket

FAQ

Is Claude Code free with these models?

Claude Code itself is free to install; the models answer on each provider's free tier, on your own account. Free open models are weaker than Claude.

Which free model is best for Claude Code?

It changes as providers update their lists. pocket reads each provider's live model list and picks a strong tool-calling model for you; pocket models shows the current pick.
