Codex usage limit: keep Codex working on your next key

Codex stops when your ChatGPT plan or API key runs out. pocket gives Codex a list of keys instead of one, and moves to the next when a provider refuses for quota.

How it works with Codex

  • Codex CLI: pocket adds a pocket profile to ~/.codex/config.toml (with a backup). Run codex-pocket; plain codex is unchanged.
  • Codex app: one click on the setup page points the whole app at pocket. That includes codex in a terminal while it's on. Disconnect puts your config back byte for byte.

pocket speaks the Responses API Codex uses, including apply_patch and MCP tools.

Set it up

$ npm i -g @zerwone/pocket
$ pocket

Paste free keys, click Connect next to Codex CLI or Codex app.

What you give up

Fallback models are open models, weaker than OpenAI's best. Hosted tools like web search don't carry over to other providers.

FAQ

What do I do when Codex says I hit my usage limit?

Wait for the reset, add an OpenAI API key, or run Codex through pocket so it moves to your next key (Groq, NVIDIA, OpenRouter or your own) when one runs out.

Does pocket change my normal Codex setup?

The CLI option only adds a pocket profile, so plain codex is unchanged. The Codex app option switches all of Codex until you disconnect it, and pocket restores the file exactly.
