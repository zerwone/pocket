Claude Code usage limit reached: how to keep working

When Claude Code stops with a "5-hour limit reached" or "weekly limit" message, you have four options. Here they are, including when pocket is the wrong tool.

The four options

  1. Wait for the reset. The message says when. Free, and you keep Claude's best models.
  2. Turn on usage credits or use an Anthropic API key. Same models, paid per token.
  3. Point Claude Code at one other provider, for example OpenRouter. Works until that provider's limit too.
  4. Run it through pocket. pocket tries your keys in order: your paid key first if you have one, then free keys from Groq, NVIDIA and OpenRouter. When one says "limit reached" (HTTP 429), the next one answers, and the session tells you which model is now working.

With a Pro or Max plan

Keep using plain claude on your plan. When it hits the limit, run claude-pocket in the same project folder. It runs Claude Code on API keys instead of your plan login, so your files carry over but the conversation does not: ask Claude for a short handoff note in CLAUDE.md before you switch.

Set it up

$ npm i -g @zerwone/pocket
$ pocket

pocket opens a setup page: paste free keys (each has its signup link), click Connect next to Claude Code, then run claude-pocket instead of claude.

What you give up

Free models are weaker than Claude's. They handle routine edits and questions; review their work on hard changes. Free keys have limits too: when all of them are spent, the agent stops, as it would without pocket.

FAQ

Why does Claude Code say "5-hour limit reached"?

Claude plans give Claude Code a usage allowance per 5-hour session and per week. The message names the reset time. It is a plan limit, not an error in your project.

Can Claude Code keep working after the limit?

Yes, on API keys: usage credits or an Anthropic API key keep Claude models; pocket can also fall back to free keys from Groq, NVIDIA and OpenRouter, which run weaker open models.

Does pocket use my Claude subscription?

No. claude-pocket runs Claude Code on API keys you add. Keep using claude on your plan and switch to claude-pocket when the plan is out.
